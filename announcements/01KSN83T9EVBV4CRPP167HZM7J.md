With the release of "Spider-Noir", there are two versions of this show. One version is color and the other is "Authentic Black and White". There is now a format available for use to prefer these B&W variant of the show since the default release is colorized. Add the "Spider-Noir Authentic B&W" format to your TV profile and score it at 1500 to always prefer those versions of the show.
